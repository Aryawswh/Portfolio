Project Description

This project focuses on designing and simulating a PLC- and HMI-based control and safety system for a three-phase production separator used in upstream oil and gas facilities. The system design was developed using real industrial documentation including P&ID and SAFE Chart references provided by PT Medco E&P Indonesia.

System Analysis

The project began with analysis of the Basic Process Control System (BPCS) and Safety Instrumented System (SIS). Process variables such as pressure, level, and valve control were mapped from the P&ID to understand normal operation and emergency shutdown logic.

  • Identification of key process instruments and control loops
  • Evaluation of BPCS and SIS functional roles
  • Risk assessment using Layers of Protection Analysis (LOPA)
  • Development of SAFE Chart cause-and-effect logic
Control System Simulation

The control and safety logic was implemented using EcoStruxure Machine Expert through full software simulation. The system includes signal scaling, alarm handling, shutdown logic, and safety interlock mechanisms.

  • Analog signal scaling (4–20 mA)
  • Alarm thresholds (HH, H, L, LL)
  • Process Shutdown (PSD) and Unit Shutdown (USD) logic
  • Safety interlocks and reset mechanisms
  • Maintenance Override Switch implementation
HMI Development

A real-time operator interface was developed in Vijeo Designer to visualize process variables and alarm conditions using Modbus TCP/IP communication.

System Validation

The system was validated through simulation of normal and abnormal operating conditions, including pressure and level deviations and emergency shutdown scenarios.
