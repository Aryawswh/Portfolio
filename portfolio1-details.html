Project Description

As part of my final-year capstone project, I developed a This project was conducted as part of my final-year capstone, in collaboration with the Surface Engineering Division of PT Medco E&P Indonesia. The focus was on designing and simulating a control and safety system for a three-phase production separator, a vital part of surface facilities in upstream oil and gas operations. In this real-world industrial setting, PT Medco E&P Indonesia acted as the facility owner and provided key engineering documentation, including the P&ID and SAFE Chart (Cause & Effect Matrix). The implementation of the physical control panel and instrumentation systems was outsourced to a third-party vendor.

🔍 Stage 1: Analyzing the Existing BPCS and SIS

The project began with an in-depth analysis of the Process Control System (BPCS) and the Safety Instrumented System (SIS) implemented in the separator unit. Drawing from the system’s Piping and Instrumentation Diagram (P&ID), I mapped out key process variables including:

  • Pressure (PT, PZT)
  • Level (LT, LZT)
  • Valves (LCV, SDV)

I studied how the BPCS is responsible for maintaining process stability under normal operating conditions through continuous monitoring and automatic control. Meanwhile, the SIS is designed to detect abnormal scenarios such as overpressure or low fluid level and intervene by triggering automatic alarms and shutdowns to prevent unsafe operating states.

🛡️ Stage 2: Applying LOPA for Risk Assessment

To evaluate the adequacy of the existing protection, I conducted a Layers of Protection Analysis (LOPA). This semi-quantitative method helped identify whether sufficient safety barriers were in place for each process hazard. The protection layers assessed included:

  • Inherent process design
  • Basic Process Control System (BPCS) control loops
  • Alarm systems and operator intervention
  • Safety Instrumented System (SIS) triggered automatic shutdowns
  • Physical safeguards (e.g., Pressure Safety Valve (PSV), bund wall)
  • Fire & Gas System (planned implementation)
  • Emergency response plans (plant-level and community-level)

The insights obtained from the LOPA formed the basis for designing the SAFE Chart logic in the next stage, which defines the system’s cause-and-effect responses.

🧠 Stage 3: Designing the SAFE Chart

Using AutoCAD 2025, I constructed a detailed SAFE Chart (Safety Analysis Function Evaluation) a visual cause-and-effect matrix that illustrates how specific process deviations (e.g., high pressure or low liquid level) should trigger alarms, valve closures, or complete system shutdowns.

💻 Stage 4: Simulating the Control and Safety Logic

The system logic was implemented using EcoStruxure Machine Expert, focusing entirely on ]software-based simulation without the use of physical PLC hardware. Key control functions developed in the simulation included:

  • Analog signal scaling (4–20 mA)
  • Alarm triggering based on setpoints: HH, H, L, and LL
  • Shutdown logic including Process Shutdown (PSD) and Unit Shutdown (USD)
  • Reset and interlock mechanisms for safety validation and restart
  • Maintenance Override Switches (MOS) to safely bypass automatic shutdowns during maintenance
👁️ Stage 5: Designing the HMI Interface

An intuitive HMI interface was developed in Vijeo Designer, simulating real-time data acquisition and control visualization. The HMI displays:

  • Live pressure and level readings
  • Valve indicators (LCV and SDV status)
  • Alarm conditions with color-coded alerts
  • Auto/manual modes for valve actuation
  • Trend graphs of valve movements over time
  • Manual ESD button and reset features

Communication between the simulated PLC and HMI was established using Modbus TCP/IP protocol.

🔬 Stage 6: System Validation via Simulation

The system was tested through a series of simulations representing both normal operation and emergency conditions, including:

  • High / Low Pressure → Alarm triggered and Process Shutdown (PSD) activated
  • High Liquid Level (HH) → Alarm triggered and Process Shutdown (PSD) activated
  • Low Liquid Level (LL) → Alarm triggered and Unit Shutdown (USD-1) activated
  • Manual ESD Activation → Instant shutdown of all SDVs, regardless of sensor input
  • Maintenance Override Switch (MOS) Active → Alarm condition ignored; system continues running for maintenance operations

Each condition was cross-verified using manual calculations and compared with the simulated HMI responses. For example, when the level sensor indicated 50%, the valve (LCV-104) opened to 45°, precisely matching the expected value using linear scaling (90° × 50% = 45°).
