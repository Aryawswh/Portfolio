Project Information

  • Project Tittle: Design of Control System and Safety System in Production Separator Based on PLC and HMI
  • Field: Control Systems and Instrumentation
  • Tools Used: EcoStruxure Machine Expert, Vijeo Designer, AutoCAD

Project Description

The main focus is the automatic control of the fluid separation process, as well as the prevention of hazardous conditions through interlocks and shutdown systems.

1. P&ID Analysis to SAFE Chart

The process starts with a P&ID (Piping and Instrumentation Diagram) analysis to understand the fluid path, location of instruments (such as pressure, level, temperature transmitters), and actuator equipment (valves). From the P&ID, critical parameters for control and safety systems are determined. Next, a SAFE Chart is prepared in AutoCAD, which describes the relationship between:

  • Process Variable (for example: separator pressure is too high)
  • Alarm logic (warning to operator)
  • Shutdown logic (for example: closing inlet valve in case of overflow)
2. Control Logic (PLC Logic)

The control logic was implemented using EcoStruxure Machine Expert with ladder diagram programming. Analog input signals (4–20 mA) from transmitters were scaled into readable process values such as level (%) or pressure (psig).

  • Create alarm and shutdown logic, such as: when the level exceeds the high-high limit, the system will enter the shutdown state, the valve will close automatically
  • Operation is available in two modes: Manual and Auto, particularly for LCV (Level Control Valve) control. In Auto mode, the LCV is regulated automatically based on level input. In Manual mode, operators can override control and adjust valve position manually
3. HMI design

The Human-Machine Interface (HMI) was built using Vijeo Designer, providing intuitive and user-friendly visualization.

  • HMI pages include Overview, Alarm, and Interlock Status
  • Colors and animations are used to clarify status, such as red, yellow, green
  • The system also features a graphical display of LCV opening trends against time, making it easy to monitor control performance in real-time
  • Auto/Manual selection for LCV is also available via HMI, enabling smooth transitions between automatic and manual operations
4. Automatic Control System

The automatic system maintains the liquid level inside the production separator, based on feedback from the Level Transmitter (LT).

  • The system is designed to keep the level within a safe operating range: Low (1'-0"), High (2'-3"), and a normal level at 1'-8"
  • Level Control Valve (LCV) automatically adjusts its position to maintain the level as close as possible to the normal setpoint (1'-8")
  • This automatic regulation supports process efficiency, prevents overflow or liquid starvation, and contributes to operational safety
5. Simulation & Validation

Before deployment, the entire control system was validated through simulation to ensure proper functionality under various scenarios.

  • Alarm and shutdown sequences were verified against the previously developed SAFE Chart, ensuring that all defined interlocks, alarms, and shutdown conditions are triggered correctly and consistently
  • Test scenarios covered normal operation, abnormal conditions, and trip logic
  • Transitions between Auto/Manual modes were also tested to confirm reliable behavior during operator intervention
  • The shutdown hierarchy validation ensures that the system executes the shutdown sequence according to the intended design and meets safety and process control requirements
