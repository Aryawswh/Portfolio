Project Description

This project is an IoT-based smart medicine box designed to automate medication reminders and monitor patient interaction. The system integrates embedded control, wireless communication, and Android mobile applications to support scheduled medication management.

System Architecture

The system uses an Arduino Nano as the main controller, supported by sensors and actuators to automate the opening, monitoring, and closing of the medicine box.

  • RTC module for real-time medication scheduling
  • Ultrasonic sensor to detect patient interaction
  • Servo motor for automated lid control
  • Buzzer for audio reminders
  • Non-contact temperature sensor for health monitoring
  • LCD display for real-time system feedback
IoT Connectivity

An ESP8266 (NodeMCU) module connects the system to Firebase Realtime Database, allowing medication schedules to be configured through an Android application. The device synchronizes with the cloud to trigger reminders and record usage events.

Mobile Integration

An Android application was developed to manage medication schedules and monitor system status. This integration demonstrates end-to-end communication between embedded hardware, cloud database, and mobile user interface.
